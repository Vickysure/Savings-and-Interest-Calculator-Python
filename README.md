##  Project Overview

A Python-based Savings & Interest Calculator developed as a practical case study to simulate savings growth and interest calculations. The project demonstrates the application of core Python programming concepts to a real-world financial scenario.

##  Project Objectives

- Calculate savings and interest over a specified period.
- Track savings growth and progress toward a savings goal.
- Categorize savings outcomes.
- Generate a structured savings report.
- Apply Python programming concepts to solve a practical financial problem.

##  Tools & Technologies

- Python
- Jupyter Notebook

## Python Concepts Applied

- Variables
- Conditional statements
- `for` loops
- `while` loops
- Functions
- Input validation
- Variable scope
- Formatted output
- Financial calculations

## Project Workflow

1. Collect user input
2. Validate input
3. Perform savings and interest calculations
4. Track savings growth
5. Evaluate savings goals
6. Categorize the savings outcome
7. Generate a savings report

##  Problem-Solving Approach

The project involved breaking a real-world savings scenario into smaller logical components and implementing each component using Python.

This approach helped transform a financial problem into a functional programming solution.

## Project Restrictions

The project was completed without using:

- Classes
- File handling
- Exception handling
- External Python libraries
- Regular expressions
- Advanced Python concepts not taught in the Study Group
